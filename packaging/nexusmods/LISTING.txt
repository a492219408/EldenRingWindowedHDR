Mod Name
========
Elden Ring Native Windowed HDR

Short description (TEXT, 253 characters)
========================================
Enables Elden Ring's native HDR rendering in Borderless Windowed and Windowed modes through ModEngine3, with in-game toggling, saved-state restoration, and strict version safety checks. Requires an HDR display with Windows HDR enabled. Offline use only.

=================

GitHub Description (TEXT, 228 characters)
=========================================
